A 99-word monologue spoken by a Dark Lord who is secretly just very tired: three centuries after taking his brother's sword, he greets the hero, loses the thread mid-sentence, and admits his scheme — the seventh seal, the gate, the tithe — now runs on its own. The weariness lives in the pauses and deflections, never in a plain complaint, and the last line lands the sting. Deterministic, model-free Python with no dependencies; the monologue is validated on every run (non-empty, at most 600 characters, about 100 words).

## Run it

```sh
python3 main.py
```

Check the monologue without writing anything:

```sh
python3 main.py --verify
```
